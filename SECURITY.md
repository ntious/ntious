# Security policy

This repository contains the public profile content for `github.com/ntious`. It intentionally contains no application runtime, secrets, analytics, visitor tracking, or third-party executable code.

## Reporting a concern

Do not include credentials, personal data, unpublished research data, student information, or other sensitive material in a public issue.

For a security or privacy concern, contact Isaac K. Nti through the verified professional channels listed in the [University of Cincinnati Research Directory](https://researchdirectory.uc.edu/p/ntiik). Provide only the minimum information needed to establish a secure follow-up channel.

## Supported content

Only the current default branch is maintained. Historical versions of profile text and images are not supported.
